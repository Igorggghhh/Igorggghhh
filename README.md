
Фрактально-волновая генерация левоусечённых простых чисел: Преодоление статистического предела

 Аннотация

В работе впервые представлен метод генерации левоусечённых цепочек простых чисел до 30 цифр, основанный на фрактально-волновой алгебре. Преодолен предел статистических ожиданий (24 цифры).
